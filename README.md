# ההקלטות שלי

אפליקציית אנדרואיד אישית להקלטת שיעורים, הרצאות ופגישות ארוכות. כל ההקלטות נשמרות רק בטלפון.

**להורדה:** https://tzipdvir-afk.github.io/haklatot/

## מצב נוכחי
שלב 0 (תשתית): אפליקציית בסיס בעברית, אייקון, בנייה אוטומטית ב-GitHub, דף הורדה ועדכונים מתוך האפליקציה.

## מבנה הפרויקט
| תיקייה / קובץ | מה יש בה |
|---|---|
| `app/src/main/java/.../MainActivity.kt` | המסך הראשי |
| `app/src/main/java/.../update/` | בדיקת עדכונים, הורדה ופתיחת מסך ההתקנה |
| `app/src/main/java/.../ui/` | צבעים ועיצוב (עברית, ימין-לשמאל, מצב כהה) |
| `app/src/main/res/` | אייקונים, טקסטים, הגדרות מערכת |
| `site/` | דף ההורדה (GitHub Pages) |
| `.github/workflows/build.yml` | הבנייה והפרסום האוטומטיים |
| `version.properties` | מספר הגרסה |
| `release-notes.txt` | "מה חדש" שמוצג באפליקציה ובדף ההורדה |
| `design/` | תמונת המקור של האייקון ותצוגה מקדימה |

## פרטיות
האפליקציה פונה לאינטרנט רק כדי לבדוק אם יש גרסה חדשה (קריאת קובץ `version.json` מ-GitHub Pages) ולהוריד אותה. שום מידע לא נשלח מהטלפון.

ראו גם: [BUILD.md](BUILD.md), [LICENSES.md](LICENSES.md).
